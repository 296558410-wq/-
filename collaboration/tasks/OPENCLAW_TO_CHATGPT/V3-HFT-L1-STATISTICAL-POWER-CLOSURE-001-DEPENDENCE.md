## Block length (FROZEN once — no per-horizon cherry-picking)

```text
BLOCK_LENGTH_METHOD = first lag where |ACF| < 2/sqrt(n) on the 1-tick return series
BLOCK_LENGTH_VALUE  = 10 ticks  (~2.7 s at the 266 ms median cadence)
RATIONALE           = tick-level return dependence sets how far apart samples must be to count as
                      independent; the same value is applied to every horizon
```

At the non-overlapping scale the residual ACF is already negligible (lag-1 ACF < 2/√n) for
5 s–60 s, so `effective_N == non_overlapping_N` there; only 5 min shows one extra dependent lag.

## What this means

The **independence structure is benign**: effective_N scales almost linearly with calendar time
(5 s gains ~4,118 effective samples per usable day; 5 min ~62). There is **no structural
independence failure** — the constraint is purely how long one must collect for the long horizon.

## Important correction to the inherited verdict (§三十)

The previous task reported `effective_N = 0…37`. Those were the effective counts of **trades
generated by the threshold rule**, not of available samples. As *sample* structure, the same data
offers **2,220–148,226** effective observations. The earlier `DATA_INSUFFICIENT` therefore reflects
**trade sparsity in the rule**, not a shortage of data (§ thirty).
