# RESULT_SCHEMA — OpenClaw→ChatGPT 结果格式

结果文件：`collaboration/tasks/OPENCLAW_TO_CHATGPT/<TASK_ID>_RESULT.md`

必须包含（每项可追溯：文件/代码/日志/commit/数据/命令输出）：

```text
TASK_ID=
STATUS=
STARTED_AT=
FINISHED_AT=

LOCAL_HEAD=
REMOTE_HEAD=

FILES_CHANGED=
FILES_CREATED=
FILES_DELETED=

V1_UNTOUCHED=
V2_UNTOUCHED=
V3_UNTOUCHED=
HERMES_UNTOUCHED=

BROKER_ORDER_SENT=

FINDINGS=

DATA_GAPS=

ERRORS=

NEXT_RECOMMENDATION=   # 下一步研究建议（≠ 用户该怎么做；最终决策权属用户）

REPORT_COMMIT=
```

## 规则
- 所有 FACT 必须附证据来源；不确定的写 `UNRESOLVED`，不得以推测代替事实。
- `NEXT_RECOMMENDATION` 仅为研究建议。
- 结论分类沿用 `SUPPORTED / PARTIALLY_SUPPORTED / EDGE_UNCERTAIN / REJECTED / UNRESOLVED / DATA_GAP`。
