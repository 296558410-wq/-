## 0. 一句话结论（最重要）

**绝大部分经典"交易手艺"（让赢家奔跑、凸性出场、金字塔、蜡烛/多周期趋势）是在管理一个"方向性趋势 edge"——而我们 E5 级可及测试空间内没有方向 edge。**
所以这些手艺对我们 **NOT APPLICABLE**：你不能"让根本不存在的赢家奔跑"，也不能"切割根本不存在的亏损方向头寸"。
**这本身是本轮最重要的发现：手艺是 edge 的放大器，不是 edge 的来源。**

## 2. 唯一直接挑战我们地图的新材料：RED FLAG

**"Forecast-to-Fill: Benchmark-Neutral Alpha... in Gold Futures"（arXiv 2511.08571）**
声称：黄金简单趋势+动量，2015-2025 OOS，净成本 Sharpe 2.88、MDD 0.52%、基准中性、$1B 容量。
- **直接矛盾**我们 E5 本地发现（黄金动量 F-R1 两期双源 0 SUPPORTED）。
- **红旗（不采信，需对抗复现）**：
  - 实际已实现波动仅 **0.91% 年化**（≈几乎从不持仓）；"43% 年化"是 15% vol 目标的**名义杠杆**，非真实收益。
  - Sharpe 2.88 + 月级 >50% 命中 + 低波动 = **搜索强度/过拟合的典型特征**（FL-19/20/23）。
  - 单篇、未复现、arXiv 预印本。与 Kaminski-Lo（止损仅在动量下增值）和 vol-timing 失败文献张力。
- **判定**：CONTRA-CANDIDATE（值得 OpenClaw 对抗性复现，但**不**因它动摇 E5 本地结论）。若复现证实其方法学干净，才升级。

## 3. 什么手艺对我们真实可及、有用

我们没有方向 edge，但有**风险/成本择时**（E5 vol 信息）。对手艺的真问题不是"怎么让赢家跑"，而是：

| 手艺 | 对我们的形式 | 价值 |
|---|---|---|
| 仓位/波动目标 | **vol-targeted sizing**（已有 Phase 5 FVT / R1） | 唯一硬(非方向) edge 的正确实现 |
| 成本择时 | **不在成本不利状态交易**（机会成本管理） | R1' 核心教训：无条件 gate 净负，形态条件化才可能 |
| 执行 | **执行 overlay**（micro-price 门控降滑点 ~13%） | 具体可及（HERMES-11 REC-02） |
| 不 over-trading | **避免交易过多**（成本 vs 机会） | R1'-B + 大样本教训 |
| "让赢家跑/凸性" | 无方向赢家可跑 → NOT APPLICABLE | — |

## 4. 关键机制：手艺放大 edge，不制造 edge

- **Kaminski-Lo**：止损在无动量时**减**值 → 手艺是被动依附于信号结构的（option-like）。
- **CTA 凸性**：正 gamma 来自"持续趋势中加仓"，前提是趋势存在。
- **MDPI**：出场救不了坏信号。
- → **对无方向 edge 的我们，交易手艺的边际价值 ≈ 0（除 vol-sizing/成本择时/执行这几个本身就是风险层的）**。

## 5. 蜡烛 / 多周期 / 趋势跟踪

- 未找到任何"genuinely different mechanism"——证据是 REPACKAGING（把本地已 REJECTED 的方向信号换标签）。
- 例外：**多周期作为"风险/状态分层"**（用 H4/H1 做 vol-regime 而非方向）可能与 E5 一致——这是 R1 的领域，非新发现。

## 6. 时间/状态纪律

- 蜡烛 MFE/MAE 是**事后数据**（hindsight）——不能作实时出场输入（chartmini 明示，与 FL-01/11 一致）。
- 出场规则与参数强耦合 → 无独立于信号的出场 edge。
