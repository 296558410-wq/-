## 1. MARKET UNDERSTANDING MAP（我们理解到什么程度）

### 1.1 有证据支持的市场结构（机制层）
| 结论 | 证据 | 状态 |
|---|---|---|
| **波动率/活跃度是"市场能量"状态变量**：activity/rvol/spread 高度自相关、跨期稳定（2023-24 与 2026 同构） | Phase 3/4/5：非重叠 OOS IC 0.6（activity→vol）；双源互证 | ✅ SUPPORTED |
| **M1 尺度存在可辨识、持续的状态**：GMM 自动发现 6 态；典型持续 3-12 分钟；**高活跃-高波动（有序扩张）与高波动-活跃回落（流动性撤离型压力）是不同状态** | phase6_states.json（FXTM 2026）；DUKA 2023-24 复现 vol 分层 | ✅ SUPPORTED（vol/activity 维度） |
| **状态携带未来波动信息，不携带方向信息**：所有状态 fwd_ret≈0；fwd_vol 随状态单调 | state profiles（两窗口） | ✅ 方向层一致结论 |
| **DUKA 型价差呈水平切换的流动性状态**（0.31↔0.70 级），死寂时段点差宽且持续数小时 | DUKA state S0（平均持续 480 分钟） | ✅ 存在流动性状态（feed 依赖） |
| **进入压力态主要靠波动持续性驱动**，|动量|、活跃度上升提供边际先行信号（AUC 0.60/0.53/0.53） | ✅ 弱先行 |
| 事件(≥3σ/30m)伴随 rvol 抬升与状态上移；观测时序上 spread/活跃度多为"同动或跟随"，**未见稳定领先的流动性信号**（FXTM 固定点差 feed 限制） | autopsy 原型 50 事件 | ⚠️ 待 DUKA tick 复验 |

### 1.2 相关但非机制（可否定因果的）
- spread→未来波动负相关（Phase 3/5）**是状态变量的两面**（活跃度同时压低点差与推高波动），非"点差导致波动"
- 分钟级 imbalance/flow 与收益的 session 反号效应：非重叠后不显著 → 是重叠噪声+session 组成伪影（Phase 4 已 REJECTED）

### 1.3 真正未知（诚实清单）
- **谁在推动市场**：无参与者身份数据 → 无法直接归因；只能用行为代理（活跃度/点差/失衡）间接观察
- **因果顺序**：无外生工具变量 → autopsy 只能给"观测先后"，不能证明因果
- 2023-24 与 2026 的状态**内容结构**相似（vol/activity 维度），但**转换的先行信号是否跨期稳定未验证**（DUKA tick 未就绪）
- 情绪/行为维度：目前代理变量（active/spread/impact）与价格同源，无独立情绪源 → **未建立独立情绪层**
- 状态转换的"为什么"：观察到了 vol 持续性，但驱动 vol 聚集的机制（消息簇？参与者协调？）不可观测 → UNKNOWN

## 2. MARKET STATE 定义与验证

- **定义方法**：GMM（BIC 选 k=6）于状态向量 {log rvol30, |mom30|, log range, log activity30(若可得), spread z(480)}，train 60% 拟合、全样本标注、固定 seed 可复现（`market_understanding/state.py`）
- **刻意排除日内时刻特征**：首版含 hod_sin/cos 时状态≈日历分段（伪状态）；去掉后得到纯市场能量状态（教训：特征选择决定状态语义）
- **验证**：
  - FXTM 2026：S0 静默(低 vol/低活跃/点差微宽 0.18) → S1-3 梯度 → S4 高活跃高波动(10.3%) → S5 高波动活跃回落(3.1%，平均 4.8 分钟) 
  - fwd_vol30/60 随状态单调（S0 0.0002 → S4/5 0.0005）→ **状态可预测未来波动**
  - fwd_ret 各状态≈0 → **状态无方向信息**（与 Phase 2-4 呼应）
  - DUKA 2023-24：同法复现 vol 分层 + 死寂宽点差态（跨期结构稳健）

## 3. STATE TRANSITION 分析
- 分钟级持续 3-12 分钟（S5 4.8m 最短）；转移矩阵呈对角占优（0.79-0.92）
- **进入压力/扩张态的可预测性**（OOS 非重叠 1321 块，logistic AUC）：rvol 分位 0.600（p<1e-3）＞ |mom30| 0.533（p=0.016）≈ activity 变化 0.526（p=0.056, FDR10% 边际）＞ spread_z 变化 0.491（无）
- **解释**：转换主要由波动持续性（=vol 聚集）驱动；尚未发现独立于 vol 水平的"流动性预警"（受 FXTM 点差 feed 限制）
- 状态转换后（30m）的方向：无条件可预测性≈0 —— 状态转换本身不给出方向 edge

## 4. MARKET AUTOPSY 原型
- `market_understanding/events.py + autopsy.py`：30m 窗口 ≥3σ 事件检测（50 个/3.4 个月）→ 事件前 60m/后 60m 轨迹 + 领先顺序 + 前/后状态 → markdown
- 示例输出见 `reports/phase6_autopsy_sample.md`；**明确声明**：领先顺序仅为观测时序，非因果断言
- 局限：FXTM 点差近恒定使 spread onset 无意义；activity/flow 仅在 tick 窗可用 → 下一轮用 DUKA tick 数据重做才有真正的微观尸检

## 6. 下一步路线图（按证据优先级）
1. **DUKA tick 全量（~85% 待下载）→ 真正的微观尸检**：tick 级 autopsy（点差动态/失衡/成交强度领先性）+ 状态先行信号跨期复验——回答"流动性撤离是否领先价格/波动"
2. **决策尺度下移**：基于状态寿命（3-12 分钟），建立 1-5 分钟决策 + tick 观察的执行模拟（Phase 5 未竟的 maker/taker 模拟）
3. **自适应 vol targeting**（regime 触发）把 Phase 5 RISK_ALPHA 泛化到全 regime
4. **参与者行为代理独立化**：尝试从成交强度/订单到达过程（双峰/突发特征）分离"信息到达"与"流动性供给"两个不可观测过程的指纹
5. 若 DUKA 复验后仍无方向 edge → 正式宣告方向层关闭，集中 execution/risk 层工程化

## 7. 结论
**理解程度**：我们确认了 XAUUSD M1 尺度的主导可观测结构是**波动-活跃度-流动性状态**（跨期稳定、可预测、无方向信息）；方向运动在本观测层上无可重复利用的信息；价格形成过程的更底层（谁/为何）超出当前数据可辨识范围——诚实标记 UNKNOWN。**理解本身暂未直接产出 alpha**，但它把研究资源从方向预测导向了两个有证据的价值面（执行择时、波动定仓）与一个明确的数据缺口（tick 级流动性先行性）。
